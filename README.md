# Seznam českých hashových kanálů v MeshCore

Oficiální seznam českých hashových kánálů je na wiki [meshcore.cz/kanaly](https://meshcore.cz/kanaly), nicméně tento seznam není aktualizovaný. Cílem tohoto repa je usnadnit aktualizaci a registraci nových hashových kanálů. 

Pokud chcete přidat nový nebo odebrat starý nepoužívaný kanál, tak můžete udělal přímo `Pull Request` s úpravou nebo vytvořit nové `Issue` a zadat požadavek na úpravu seznamu.
